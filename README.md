# Homebrew Tap for AgentOps

This tap contains the formula for [AgentOps](https://github.com/boshu2/agentops), the Knowledge Flywheel CLI for AI-assisted development.

## Installation

```bash
brew tap boshu2/agentops
brew install agentops
```

## Usage

```bash
# Check version
ao version

# Initialize knowledge base
ao init

# Inject knowledge into session
ao inject

# Check flywheel health
ao badge
```

## Updating

```bash
brew update
brew upgrade agentops
```
